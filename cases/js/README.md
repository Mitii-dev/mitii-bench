# JavaScript cases

Cases for `starters/js/*`. Add new cases under `atomic/{category}/{slug}/`.

| Category | Path | Starters |
|---|---|---|
| Frontend | `atomic/frontend/` | `react-js`, `next-js` (separate case folders) |
| Backend | `atomic/backend/` | `node`, `nest-js` |

Regenerate corpora: `pnpm generate:react-frontend` · `pnpm generate:node-backend`.
