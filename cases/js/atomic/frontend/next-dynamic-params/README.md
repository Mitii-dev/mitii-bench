# Next.js App Router: Dynamic URL Parameters

## Goal

Build a product detail page using Next.js App Router dynamic segments and `useParams`.

## Starter

`next-js` — Next.js App Router — implement in `app/page.js` as a client component (`"use client"`).

## Packages

_None beyond the starter._

```bash
pnpm case:dry-run frontend-next-dynamic-params
```

## How we check

- Recipes in `task.yaml` under `checks:`
- `solution/` is dry-run only (never shown to the agent)
