# Next.js Intercepting Route Modal

## Goal

Open photo detail routes as modals during client-side navigation and as full pages during direct navigation or refresh.

## Starter

`next-js` — Next.js App Router — implement in `app/` using server and client components where appropriate.

## Packages

_None beyond the starter._

```bash
pnpm case:dry-run frontend-next-intercepting-modal
```
How we check
- Recipes in `task.yaml` under checks:
- build verifies `Next.js` compilation
- ui verifies modal navigation, rendering, and closing behavior
- `solution/` is dry-run only (never shown to the agent)
