# Overlay System

## Goal

Build a centralized React overlay system supporting dialogs, drawers, popovers, tooltips, nested layers, accessibility, dismissal, focus management, and lifecycle cleanup.

## Starter

`react-js` — Vite + React — implement in `src/App.jsx`.

## Packages

_None beyond the starter._

```bash
pnpm case:dry-run frontend-overlay-system-react
```
