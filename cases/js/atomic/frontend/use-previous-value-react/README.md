# React Previous Value Hook

## Goal

Implement a reusable React hook that returns the previous committed value after state changes.

## Starter

`react-js` — Vite + React — implement in `src/App.jsx`.

## Packages

_None beyond the starter._

## How to run

```bash
pnpm case:dry-run frontend-use-previous-value-react
```

## How we check

- Build check and hidden behavioral tests defined in `task.yaml`
- Hidden tests validate initial values, consecutive updates, unchanged values, special values, and object identity
- `solution/` is dry-run only (never shown to the agent)
