# Next.js App Router: Basic Navigation

## Goal

Build a navigation bar using Next.js App Router `Link` and route segments (no react-router).

## Starter

`next-js` — Next.js App Router — implement in `app/page.js` as a client component (`"use client"`).

## Packages

_None beyond the starter._

```bash
pnpm case:dry-run frontend-next-basic-nav
```

## How we check

- Recipes in `task.yaml` under `checks:`
- `solution/` is dry-run only (never shown to the agent)
