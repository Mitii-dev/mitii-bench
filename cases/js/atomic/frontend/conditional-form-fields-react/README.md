# Conditional Form Fields

## Goal

Build a registration form that dynamically displays and validates
fields based on the selected account type.

Individual accounts require common fields, while Business accounts
also require company-specific information.

## Starter

`react-js` — Vite + React — implement in `src/App.jsx`.

## Packages

_None beyond the starter._

## Validation

```bash
pnpm case:dry-run frontend-conditional-form-fields-react
```
