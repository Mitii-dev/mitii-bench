# Notification Center

## Goal

Build a React notification center that supports filtering and managing
individual and bulk read/unread notification states.

## Starter

`react-js` — Vite + React — implement in `src/App.jsx`.

## Packages

_None beyond the starter._

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)

```bash
pnpm case:dry-run frontend-notification-center-react
```
