# Drag and Drop List Reordering

## Goal

Build an interactive task list that allows users to reorder
items using the HTML5 Drag and Drop API.

The list must update React state whenever an item is dropped
at a different position.

## Starter

`react-js` — Vite + React — implement in `src/App.jsx`.

## Packages

_None beyond the starter._

## Validation

```bash
pnpm case:dry-run frontend-drag-drop-list-react
```
