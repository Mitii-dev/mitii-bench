# Portals (React.createPortal)

Build a tooltip component that renders outside the parent DOM node into `#modal-root`.

## Starter

## Packages

```bash
pnpm case:dry-run frontend-portal-tooltip-react
```

- Hidden automated tests in `tests/` (injected only at check time)
