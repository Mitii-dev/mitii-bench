# Audio Player UI

## Goal

Build a mini custom audio player interface.

## Starter

`next-js` — Next.js App Router — implement in `app/page.jsx` as a client component (`"use client"`).

## Packages

_None beyond the starter._

```bash
pnpm case:dry-run frontend-audio-player-ui-next
```

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)
