# WebSocket Live Updates Dashboard

## Goal

Build a real-time React dashboard that processes WebSocket events,
updates metrics and alerts, and manages connection lifecycle and retries.

## Starter

`react-js` — Vite + React — implement in `src/App.jsx`.

## Packages

_None beyond the starter._

## How to run

```bash
pnpm case:dry-run frontend-websocket-live-updates-react
```
