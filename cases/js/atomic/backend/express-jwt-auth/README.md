# Express JWT Authentication Middleware

## Goal

Build a route protection middleware validating Bearer JWTs.

## Starter

`node` — Node.js starter — implement under `src/`.

## Packages

- `jsonwebtoken`

```bash
pnpm case:dry-run backend-express-jwt-auth
```

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)
