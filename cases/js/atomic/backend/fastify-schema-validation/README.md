# Fastify Schema Validation & Hooks

## Goal

Build a Fastify route using built-in JSON schema validation.

## Starter

`node` — Node.js starter — implement under `src/`.

## Packages

- `fastify`

```bash
pnpm case:dry-run backend-fastify-schema-validation
```

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)
