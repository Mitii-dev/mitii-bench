# Socket.io JWT Authentication Handshake

## Goal

Build an authentication guard for incoming Socket.io connections.

## Starter

`node` — Node.js starter — implement under `src/`.

## Packages

- `socket.io`
- `jsonwebtoken`

```bash
pnpm case:dry-run backend-socketio-jwt-handshake
```

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)
