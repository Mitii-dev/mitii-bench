# Prisma ORM Transaction Handling

## Goal

Build an e-commerce balance transfer using Prisma interactive transactions.

## Starter

`node` — Node.js starter — implement under `src/`.

## Packages

- `prisma`
- `@prisma/client`

```bash
pnpm case:dry-run backend-prisma-balance-transfer
```

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)
