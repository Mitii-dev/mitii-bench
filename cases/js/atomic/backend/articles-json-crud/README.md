# Rest API CRUD with File Storage Backup

## Goal

Build a complete RESTful API for managing articles with CRUD operations, saving data to local JSON file persistence safely using temporary atomic write patterns.

## Starter

`node` — Node.js starter — implement under `src/`.

## Packages

_None beyond the starter._

```bash
pnpm case:dry-run backend-articles-json-crud
```

## How we check

- Recipes in `task.yaml` under `checks:`
- Hidden automated tests in `tests/` (injected only at check time)
- `solution/` is dry-run only (never shown to the agent)
